# Visual sources

- `banner.svg` and `assets/banner-*.svg`: original SVG diagrams created for this
  profile. No scripts, external fonts, foreignObject, embedded HTML, tracking
  pixel or remote resource. Introductory motion finishes within 4.4 seconds;
  reduced-motion preferences are respected and the final diagram stays visible.
- `assets/projects/*.webp`: real screenshots already published by the owner on
  https://www.grimael.dev/. Copied unchanged from the owner's portfolio assets.
  They depict OpenDataViz, NPS, RH IA Pro and the Churn Telecom dashboard.
- Existing `profile.png` and `profile.jpeg` are preserved unchanged.

The README uses native Markdown and GitHub-supported HTML. Preview files under
`.preview/` are local review artifacts and are not intended for publication.
